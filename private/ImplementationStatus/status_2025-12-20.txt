   🎯 MODEL SPECIFICATIONS

   QRdet Model (Single-Class QR Detection)
     Input:  [batch=1, channels=3, height=640, width=640]
     Output0: [batch=1, channels=37, predictions=8400]
              ├─ Indices 0-3:   Bounding box (cx, cy, w, h)
              ├─ Index 4:       Confidence score
              └─ Indices 5-36:  Mask coefficients
     Output1: [batch=1, channels=32, height=160, width=160]
              └─ Segmentation prototype masks

   ⚠️  CRITICAL NOTE: This is single-class detection (37 channels, not 116)
       Standard YOLOv8 would have [1, 116, 8400] for multi-class COCO detection.
       Migration path for multi-barcode support documented in MODEL_FORMAT.md.

   # One-time setup
   make setup-python
   make model

   # Development
   make build
   ./bin/qrdetect -input photo.jpg -output result.png

   # Production (single binary)
   make build-embedded
   ./bin/qrdetect -input photo.jpg -output result.png

   # Library usage (see README.md for full example)
   detector, _ := qrdet.NewDetector(qrdet.DefaultConfig())
   detections, _ := detector.Detect(image)
   detector.Close()
